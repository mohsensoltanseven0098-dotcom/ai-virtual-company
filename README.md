# شرکت مجازی هوش مصنوعی | AI Virtual Company

یک داشبورد سه‌بعدی تعاملی از دفتر مجازی شرکت ساخت سایت، اپلیکیشن و کدنویسی با ایجنت‌های هوش مصنوعی.

## بخش‌ها

| بخش | تعداد ایجنت | توضیح |
|------|-------------|--------|
| اتاق کدنویسی | ۱۰ | توسعه سایت، اپلیکیشن و کدنویسی |
| مدیریت مالی | ۵ | فاکتورها، پرداخت‌ها و گزارش مالی |
| تولید محتوا | ۱۰ | تولید و انتشار محتوا در اینستاگرام و تلگرام |
| پشتیبانی مشتری | ۵ | پاسخ به مشتریان در اینستا و تلگرام + ارجاع به بخش‌ها |
| مدیریت کل (HQ) | ۲ | هماهنگی و فرماندهی کل شرکت |

همه بخش‌ها به مرکز فرماندهی متصل هستند.

## ویژگی‌ها

- صحنه سه‌بعدی ایزومتریک با Three.js
- پلتفرم‌های شناور با دسکتاپ‌های شبیه‌سازی‌شده
- ذرات متحرک و خطوط اتصال بین بخش‌ها
- کارت‌های متریک زنده برای هر دپارتمان
- کنترل دوربین با موس (چرخش + زوم)
- رابط فارسی

## اجرا

فقط فایل `index.html` را در مرورگر باز کنید (نیازی به سرور نیست).

یا از طریق GitHub Pages / Vercel دیپلوی کنید.
